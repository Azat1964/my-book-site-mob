# Болталка на booklo.ru: что куда вставлено

Болталка встроена прямо в ваш `server.js`: отдельный сервер не нужен. Тексты берутся из вашей базы (аннотации, главы, стихи, посты блога) и из заметок в `chat/content/`.

## Что добавлено

| Файл | Что это |
|---|---|
| `lib/chat.js` (новый) | Вся логика: поиск по текстам, запрос к ИИ, лимиты |
| `chat/rules.md` (новый) | Характер и правила Болталки (можно править текстом) |
| `chat/config.json` (новый) | Приветствие и кнопки-подсказки |
| `chat/content/*.md` (новые) | Заметки об авторе, книгах, стихах |
| `public/js/chat-widget.js` (новый) | Кнопка «Поболтать» и окно чата |
| `server.js` | 2 вставки (см. ниже) |
| `public/index.html`, `about.html`, `annotations.html`, `blog.html`, `blog-post.html`, `chistoriya.html`, `contents.html` | В каждой по одной строке перед `</body>` |
| `.env.example` | Пример новых настроек |

Страницы чтения (`book.html`, `book_mob.html`) я намеренно не трогал, чтобы чат не мешал читалке.

## Установка

1. Распакуйте архив поверх папки проекта `my-book-site-mob` и согласитесь заменить файлы. Если после выгрузки вы правили `server.js` или эти html-страницы, замените только новые файлы, а правки в них внесите вручную (раздел ниже).
2. Откройте свой `.env` и добавьте:
   ```
   CHAT_PROVIDER=yandex
   ```
   Ключи `YANDEX_API_KEY` и `YANDEX_FOLDER_ID` уже используются вашим агентом продвижения, Болталка берёт те же.
   Если хотите, чтобы отвечал Claude, поставьте `CHAT_PROVIDER=anthropic` и заполните `ANTHROPIC_API_KEY`. Но Claude работает только с серверов в странах, где доступен API Anthropic. Если сайт стоит на российском хостинге, выбирайте yandex.
3. Перезапустите сервер: `node server.js`. В консоли должна появиться строка вида:
   `Болталка: загружено кусков текста: заметки 20, база 150; ИИ: yandex`
4. Откройте сайт: справа внизу будет кнопка «Поболтать».

Новые настройки (все необязательные): `CHAT_MODEL`, `SITE_URL`, `CHAT_RATE_PER_MIN` (сообщений в минуту с одного адреса, по умолчанию 12), `CHAT_DAILY_LIMIT` (всего ответов в сутки, по умолчанию 1000), `CHAT_REFRESH_MIN` (как часто перечитывать базу, по умолчанию 10 минут).

## Как это работает с закрытыми главами

Если у книги задан `free_chapters_limit`, анонимному посетителю Болталка не видит главы после лимита: ни пересказать, ни процитировать их она не может. Вошедшему читателю доступны все главы. Это то же правило, что в вашей читалке.

## Когда добавляете новые главы и посты

Болталка сама перечитывает базу раз в 10 минут. Чтобы обновить сразу, перезапустите сервер или отправьте POST на `/api/admin/chat/reload` с заголовком `x-admin-token`.

## Что можно править

- `chat/config.json`: приветствие, подпись, кнопки-подсказки.
- `chat/rules.md`: характер и границы. Например, можно разрешить ей шутить смелее или, наоборот, строже держаться текстов.
- `chat/content/`: заметки (интервью, факты, ссылки). Заголовок `# Название` начинает документ, строка `URL: …` под ним даёт ссылку для читателя. Файлы, начинающиеся с `_`, всегда целиком попадают в разговор. Остальные подбираются по теме вопроса.

## Вручную, если файлы уже менялись

В `server.js` рядом с другими `require`:
```js
const { registerChat } = require('./lib/chat'); // ИИ-болталка для посетителей (см. папку chat/)
```
и ПОСЛЕ блока `app.use(session({...}))`, перед `app.post('/api/register', ...)`:
```js
registerChat(app, pool, { requireAdmin });
```
В каждую страницу, где нужен чат, перед `</body>`:
```html
<script src="/js/chat-widget.js" defer></script>
```

## Безопасность

Ваш `.env` (с токеном Telegram, `ADMIN_TOKEN`, ключами) лежал в архиве, который вы загрузили в этот чат. Рекомендую перевыпустить токен Telegram-бота у @BotFather, сменить `ADMIN_TOKEN` и `SESSION_SECRET` и перевыпустить ключи YandexGPT и VK. Впредь собирайте архив без `.env`, `node_modules` и `.git`.
